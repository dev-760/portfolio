## Additional fixes found during verification

### 7. Search field had no accessible name

`src/components/WritingSection.tsx`

The input had only `placeholder="Search notes..."`. Placeholder text is not a reliable accessible name and vanishes on input.

- Added `id="notes-search"`.
- Added a visually hidden `<label htmlFor="notes-search">Search notes by title, summary, or tag</label>`.
- Placeholder shortened to "Search notes".
- Added `aria-label="Clear note search"` to the icon-only clear button, which previously had no name.

### 8. No empty state for a search with no results

`src/components/WritingSection.tsx`

A failed search previously rendered an empty grid with no explanation and no way forward.

Added a plain empty state naming the problem and the recovery: "No notes match &ldquo;query&rdquo;." / "Clear the search to see all 3 notes." with a Clear search button.

### 9. Note count contradicted itself

`src/components/WritingSection.tsx`

The old count read `noteArticles.length`, which excludes the featured essay, while the grid above the filter row showed it. A visitor saw three notes and a count of 2.

The filter chips are gone, so a separate count line now states the total including the featured essay, and the filtered count uses the same denominator.
